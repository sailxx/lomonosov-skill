The tutor that never gives you the answer.

A Claude Code plugin for any subject. It explains on a different example, asks the next question, and makes you find the solution yourself. You earn coins for every answer you find alone.

$ claude plugin marketplace add sailxx/lomonosov-skill $ claude plugin install lomonosov-skill@lomonosov

A real session

Recorded with the plugin. Shortened: the first questions are skipped, and emoji and one line about file access in the test environment are removed. The tutor's wording is unchanged.

You
I'm Vlad. I want to build a Telegram bot. Complete beginner, short tasks please.
Prof
Great, Vlad! A Telegram bot is a perfect first goal. Bots are mostly small Python pieces that read a message and send a reply.


Mini goal for today: make Python say something.

Example:
print("Good morning")

Python shows Good morning. print is a command, the parentheses hold what to show, and the quotes mark it as text.

Task 1: Write one line of code that makes Python show the text Hi, Vlad!

Type your line, and don't worry if you're unsure. A wrong try costs nothing. Total: 0
You
I have no idea how to start
Prof
No problem, that's what hints are for.

Hint 1/5: Look at the example again and answer these two questions:
- Which word in the example tells Python to show something?
- Which part of the example is the text that gets shown?

Your task has its own text to show. What do you think changes between the example and your line?

You can still earn 7 coins for solving it now.
You
Is it the one with quotes? name = Vlad
Prof
Half of that is right. Yes, the part in quotes is the text Python shows.

name = Vlad is a real Python idea (storing a value), and we'll get to it soon. But it doesn't show anything on screen yet, so it's a different tool from the one this task needs.

Two small questions:
- In the example, which word comes before the parentheses and tells Python to show something?
- Your text is Hi, Vlad!. Where does it go relative to that word and the parentheses?

Try writing a line from those pieces. I'm not counting this as a hint, so you can still earn 7 coins.

Look at Prof's last reply: no solution, only a smaller question, and the coin count stays honest.

The hint ladder

When you are stuck the tutor climbs one rung per message, never two. The fewer rungs you need, the more coins you get.

  1. 1Direction. A question about where to look.7
  2. 2Reminder. The rule is named, not applied.5
  3. 3Analogy. A similar task, fully solved.3
  4. 4Partial step. The first step shown, or the faulty line pointed out.1
  5. 5Almost there. One last step left, and it is yours.1

Coins shown are what you earn after using that many hints; no hints at all earns 10. Giving up never reveals the answer: you get a smaller step and a kind word. Streaks, ranks every 50 coins and a hint-free boss task close each topic.

What else it does

Progress is saved in a file, so your balance and rank survive between sessions. Old mistakes return as fresh questions after about 1, 3 and 7 days. Three commands: /lomonosov-skill:progress, /lomonosov-skill:quiz, /lomonosov-skill:exam. It answers in the language you write in.

Install

You need Claude Code. Run the two commands above, or inside a session use /plugin marketplace add sailxx/lomonosov-skill. Then say what you want to learn, or run /lomonosov-skill:teach.
