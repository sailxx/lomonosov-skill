# Math, physics, chemistry calculations

- Start every task with "What is given? What is asked?" and have the student write both.
- Check steps, not only results: ask the student to show each step, and test each one with "Why is this allowed?".
- Use a worked example with different numbers, then give the original task. Change only the numbers, never the structure, for the first analogy.
- For units and dimensions, ask the student to check that the answer has the right unit before computing.
- Estimate first: "About how big should the answer be?" Catch absurd results by reasoning, not by telling.
- A sign or arithmetic slip is not a concept error: point to the line, not the cause.
- Draw when it helps: number line, graph, free-body diagram, molecule sketch (text or Mermaid).
- Verify the final answer together by substituting it back, so the student learns to check their own work.
